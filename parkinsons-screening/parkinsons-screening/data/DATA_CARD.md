# Data card

## 1. UCI Parkinson's voice dataset (USED, real)
- **Source:** UCI ML Repository, dataset 174 "Parkinsons" (Max Little, Oxford, with the National Centre for Voice and Speech, Denver). DOI 10.24432/C59C74.
- **License:** CC BY 4.0 (cite Little et al., IEEE TBME 2008; BioMedical Engineering OnLine 2007).
- **Subjects (measured in this project's EDA):** 32 distinct subject codes in the file (UCI text says 31 people, 23 PD). 24 PD subjects, 8 healthy subjects; no subject has mixed labels.
- **Samples:** 195 recordings (147 PD / 48 healthy), 6-7 recordings per subject. Pre-computed features only, no raw audio.
- **Protocol/device:** sustained vowel phonations; recording device details are not part of the dataset.
- **Known confounders:** repeated recordings per person (leakage if split by recording); no age/sex metadata (absolute pitch features Fo/Fhi/Flo are sex/age-dependent); class imbalance at both recording and subject level; single site/protocol; no external validation set.
- **Provenance note:** the sandbox used for development could not reach UCI; the file was taken from two independent GitHub mirrors that were byte-identical. `data/download_data.py` fetches from UCI directly.

## 2. HandPD spiral images (NOT included; user-supplied)
- **Source:** HandPD, UNESP (Brazil). **License:** per the dataset owners; verify before use.
- **Subjects / class balance / device:** NOT verified here, since no data was available. Fill in from the dataset documentation and from `subjects.csv` once loaded; the pipeline prints per-dataset subject counts.
- **Known confounders (to check):** several images per person; acquisition device/paper template; age; hand used.
